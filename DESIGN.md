# Дизайн Roblox Room

Игровая страница для детей и родителей, прежде всего для телефона. Сохранить первый экран, синий, зелёный и жёлтый цвета и квадратные игровые формы. Сочетать светлые поверхности для текста с тёмными игровыми блоками. Ниже обложки — понятные дата и место, программа, полезная информация и личное приглашение. Настройки открываются отдельно и не располагаются сверху страницы. Фотография героя в демо может быть примером; её можно заменить.

Montserrat, крупные заголовки, короткие подписи, сдержанное движение с учётом reduced motion. Брать детали из DESIGN-roblox.md, избегать пустой игровой терминологии и бессмысленных декоративных карточек.
