# Приглашения BoomBala

Платформа для создания персональных сайтов-приглашений на детские дни рождения.

## Как работает

- При заказе праздника родитель выбирает комнату.
- Сотрудник создаёт приглашение в теме выбранной комнаты. Доступны четыре шаблона: Roblox, Ice, Magic и Rapunzel.
- В приглашение добавляются имя ребёнка, возраст, фото и детали праздника.
- Для приглашения создаётся отдельная ссылка и задаётся срок публикации, например одна неделя. После его окончания ссылка становится недоступна, а данные приглашения и фото удаляются.

## Размещение

Платформа размещается на Vercel.

## Текущий прототип

- Подготовлен только шаблон игровой комнаты Roblox.
- Поля редактора меняют предпросмотр в браузере; загруженное фото не отправляется и не сохраняется.
- Создание публичной ссылки, хранение приглашений и автоматическое удаление по сроку ещё не подключены.
- Иллюстрация в `assets/roblox-quest-world.png` создана специально для макета. Официальный логотип и классические аватары не используются; [правила Roblox](https://en.help.roblox.com/hc/en-us/articles/115001708126-Roblox-Name-and-Logo-Guidelines) ограничивают их коммерческое применение без лицензии.

Открой `index.html`, чтобы посмотреть макет.
