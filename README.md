# Приглашения BoomBala

Платформа для создания персональных сайтов-приглашений на детские дни рождения.

Подробная документация и план дальнейшей работы: [HANDOFF.md](HANDOFF.md).

## Как работает

- При заказе праздника родитель выбирает комнату.
- Сотрудник создаёт приглашение в теме выбранной комнаты. В прототипе представлены четыре темы: Roblox, Ice, Magic и Rapunzel.
- В приглашение добавляются имя ребёнка, возраст, фото и детали праздника.
- Планируется отдельная временная ссылка для каждого праздника и удаление данных после окончания срока. Сейчас это только локальное демо.

## Размещение

Хостинг для текущего прототипа не подтверждён. Для просмотра локально запустите сервер, как описано ниже.

## Текущий прототип

- На главном экране можно выбрать одну из четырёх комнат и перейти к настройке приглашения. Ice оформлен как зимняя открытка, Magic — как мир монстриков, Rapunzel — как сказочная книга; Roblox сохраняет игровой дизайн.
- Содержимое программы для новых тем приведено как пример и зависит от выбранного пакета.
- Поля старого встроенного редактора меняют только предпросмотр. В отдельном демо организатора данные праздника, фото и аудио сохраняются в `sessionStorage` текущей вкладки и не отправляются на сервер.
- Анимации работают на GSAP и ScrollTrigger 3.15.0; файлы библиотек находятся в `assets/vendor`, поэтому для запуска страницы CDN не нужен. Для пользователей, выбравших уменьшение движения, анимация отключается.
- При первом открытии предпросмотра запускается эффект шаров из [balloons-js 0.0.3](https://github.com/arturbien/balloons-js). Локальная версия в `assets/vendor` адаптирована для телефонов: шесть уменьшенных шаров, без тяжёлых SVG-фильтров и с более короткой анимацией. Лицензия лежит рядом с библиотекой.
- Создание публичной ссылки, хранение приглашений и автоматическое удаление по сроку ещё не подключены.
- Иллюстрация в `assets/roblox-quest-world.webp` создана специально для макета. Официальный логотип и классические аватары не используются; [правила Roblox](https://en.help.roblox.com/hc/en-us/articles/115001708126-Roblox-Name-and-Logo-Guidelines) ограничивают их коммерческое применение без лицензии.

Открой `index.html`, чтобы посмотреть макет.

## Демо организатора

Выберите комнату на `index.html`, чтобы перейти к настройке приглашения, или откройте список праздников через `demo.html`. Создайте праздник, откройте приглашение и заполните ответ гостя; затем вернитесь назад и откройте праздник в списке. Данные и файлы находятся в `sessionStorage` текущей вкладки. Гостям список ответивших не показывается; в демо его видно в панели организатора. Используйте только вымышленные данные. Демо-ссылка не работает у других людей или в другой вкладке. Для локальной проверки можно запустить `python3 -m http.server 8765` и открыть `http://localhost:8765/index.html`.

Это только демонстрация интерфейса: пароль, секретная ссылка организатора, публичная ссылка, серверная защита и реальное удаление данных не реализованы. Демо-приглашение проверяет истечение срока при открытии; экран после праздника показывается со следующего дня. При закрытии вкладки её демо-данные могут быть удалены браузером.

Для подключения своей базы разработчику нужно заменить хранение в `demo.js` и `guest-demo.js` серверными запросами, настроить отдельный защищённый доступ сотрудников и родителя к ответам, серверную валидацию и защиту от спама, а также плановое удаление данных и файлов после срока. Пока этого нет, персональные данные реальных гостей и аллергии в демо вводить нельзя.
